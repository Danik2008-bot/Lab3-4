# TextProcessing (Project03 + Project04)

Консольная программа на C# (.NET 8).

## Project03: обработка текста
Текст разбирается на предложения, слова и знаки препинания
(классы Text, Sentence, Word, Punctuation, парсер на регулярных выражениях).
Поддерживаются операции:
- сортировка предложений по числу слов и по длине;
- поиск слов заданной длины в вопросительных предложениях;
- удаление слов заданной длины, начинающихся с согласной;
- замена слов заданной длины на указанную подстроку;
- удаление стоп-слов (русский и английский списки в папке Data);
- экспорт текста в XML.

## Project04: конкорданс
Для каждого слова считается число вхождений и номера строк
(Dictionary и SortedSet), вывод по алфавиту.

## Запуск
dotnet run
или с другим файлом:
dotnet run -- путь\к\файлу.txt

По умолчанию используется Data/sample_en.txt.
